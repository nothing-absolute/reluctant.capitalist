# Walkthrough: Channel Script Production

We have successfully drafted the first three video scripts for the channel. Each script is built in a professional, two-column production format (Visuals / B-roll and Voiceover / Audio cues) to make it ready for recording, storyboarding, or editing.

## Production Recommendations

- **Teleprompter / Recording:** The split-column script format is designed to help you read the VO column while maintaining awareness of visual pacing. Consider using teleprompter software that lets you display script files.
- **B-Roll Collection:** Since these scripts heavily rely on nostalgic, 90s, and DIY themes, try sourcing real archival photos from the Omaha scene, old zines, ticket stubs, and cassette scans to build a highly textured, analog feel.
- **Audio Cues:** Use the music cues in the script to plan your transitions. The pacing should move from energetic skate punk to warm, tape-hiss indie acoustic tones, and finally to soft ambient space.
