**17:05 - "Local Scene" — modular Winamp-style player for escaping walled gardens**
Product idea: a personal music library + player for Linux (Debian) that is a *transition out of* Spotify/YouTube, with DIY/independent scene discovery as the soul. Not an account-based product — user-first, own-your-data. Key requirements: (1) Winamp-like player but modern UI/UX, (2) connect Spotify/YouTube Music accounts for **listening history only** (no sync), (3) acquisition from open/torrent/streaming sources, (4) built from modular existing OSS, (5) beta-testable in days, hard parts later (scrum).

2026 stack researched:
- **Player**: Nuclear (Tauri/React, AGPL, nukeop/nuclear, 18.3k★) — streams free from YouTube/SoundCloud/Bandcamp/Jamendo/Audius, Last.fm scrobble, plugin store + @nuclearplayer/plugin-sdk, MCP server, ships .deb/.AppImage/.flatpak. Closest thing to the vision out of the box.
- **Library brain**: Navidrome (Go, ~40MB RAM, .deb, Subsonic API) — auto-tag, multi-library, streams to any client.
- **Modern client**: Feishin (Flatpak/AppImage, MPV backend, scrobbles to server) — Feishin ↔ Navidrome = Spotify-like UI over your own files.
- **Acquisition**: yt-dlp core; `beets-ytimport` plugin (ytmusicapi + yt-dlp, prefers Opus, chapter-splitting, MusicBrainz auto-tag, syncs YT "liked songs" into the library); ytdl-sub (subscriptions → automated Bandcamp/SoundCloud/YT discography downloads, beets-tagged); Nicotine+ (Soulseek) for rare/DIY-only releases; Lidarr optional for torrent automation.
- **Curator**: beets (tagger/database) — the pipeline glue.
- **History layer**: ListenBrainz (open-source, MetaBrainz; native Spotify import as of Aug-2025 server release; ytm-extractor / YTMusic2listenbrainz.py for YT Music watch history; Web Scrobbler browser ext). Spotify path = request Extended Streaming History from privacy settings → import into ListenBrainz.
- **Discovery for DIY/independent** (the stated soul of the product): Bandcamp discography subscriptions via ytdl-sub, SoundCloud, Jamendo/Audius in Nuclear, internet radio.

Key architecture insight: 6 thin layers — disk library → beets curator → acquisition (yt-dlp/ytdl-sub/Nicotine+) → Navidrome server → dual players (Nuclear + Feishin) → ListenBrainz history. Everything swappable because interfaces are standard (filesystem, Subsonic API, scrobble API). Beta path ≈ half a day: Navidrome .deb → Feishin Flatpak → Nuclear → beets+ytimport for liked songs → ListenBrainz import of Spotify history → ytdl-sub subscription for first Bandcamp artists.
