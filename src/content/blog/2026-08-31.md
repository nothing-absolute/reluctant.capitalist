12:35 - OmniRoute Provider Importer + API-blocked DB-insert method
Built [local path redacted]/ — a dependency-free Python tool (omniroute_import.py) + sample providers.free.{json,csv} + README.md to import providers into the self-hosted gateway via POST /api/providers. Create schema (reverse-engineered from src/shared/validation/schemas/provider.ts): provider, name, apiKey?, priority?, globalPriority?, defaultModel?, testStatus?, providerSpecificData?.

Key finding: the create API only accepts managed / OpenAI-compatible / Anthropic-compatible ids. It REJECTS these 6 no-auth providers with Invalid provider even though their executors exist: duckduckgo-web, felo-web, theoldllm, chipotle, aihorde, veoaifree-web.

Workaround (validated live): direct INSERT into provider_connections in ~/.omniroute/storage.sqlite IS picked up by the running server immediately — NO restart needed (SQLite WAL allows concurrent writers). Added all 6 (conns 16→22, total now 26). Model namespaces now live: ddgw (6), felo (5), tllm (26), pepper (1), horde (22 LLM/passthrough), veo-free (2, video). 2092 models total.
